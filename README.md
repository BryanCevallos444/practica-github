# practica-github

Práctica del flujo completo con Git y GitHub: crear el repositorio remoto,
clonarlo en local, hacer commits y subir los cambios.

**Autor:** Bryan Cevallos ([@BryanCevallos444](https://github.com/BryanCevallos444))

## Contenido

- `saludo.js` — función básica de saludo.
- `calculadora.js` — operaciones de suma y resta.

## Uso

```bash
node saludo.js
node calculadora.js
```

## Flujo seguido

1. Crear el repositorio en GitHub.
2. Clonar el repositorio en local.
3. Crear el código básico y los 3 commits.
4. Subir los cambios a GitHub con `git push`.
